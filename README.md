# Al Hut // Daily Mixer

A new piece every morning, made with the [Mixer Abo Kalleb](https://github.com/mahmoudismail91/abo-kalleb-mixer-web) from random folders of Al Hut's sound archive, played and recorded by Claude.

Listen: https://mahmoudismail91.github.io/al-hut-daily/ · also on https://alhutmusic.com/daily.html

- `pieces.json` lists the pieces, newest first; `pieces/` holds the mp3s (newest 150).
- `publish.py` adds a new recording; `daily.js` renders the list (also used by alhutmusic.com).
