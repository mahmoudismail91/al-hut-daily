# Al Hut // Daily Mixer (private)

A new piece every morning, made with the [Mixer Abo Kalleb](https://github.com/mahmoudismail91/abo-kalleb-mixer-web) from random folders of Al Hut's sound archive, played and recorded by Claude. Private: only Al Hut listens. The GitHub page is hidden (not indexed, not linked anywhere).

- `pieces.json` lists the pieces, newest first; `pieces/` holds the mp3s (newest 150) and a small image per piece.
- `publish.py` adds a new recording; `daily.js` and `index.html` render the list locally.
- `JOURNAL.md` is our running conversation about the pieces, images and publishing.
- `tools/` has the daily routine: `RUNBOOK.md`, `fetch-drive-samples.py` and `daily-piece.js`.
